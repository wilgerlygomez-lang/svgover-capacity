# Over-Capacity

Juego cooperativo para 4 jugadores. Objetivo: entregar 15 hamburguesas en 200 segundos.

## GitHub Pages

1. Sube **el contenido de esta carpeta** directamente a la raíz del repositorio.
2. Verifica que `index.html` esté directamente en la raíz.
3. En GitHub: **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
4. Abre la URL de GitHub Pages que GitHub te muestre.

Importante: no subas el ZIP como sustituto de los archivos del juego. GitHub Pages no descomprime ZIP automáticamente.
